# Goal 0006 — Non-PDF reader parity

## Result

Implemented the authorized non-PDF parity evidence pass for TXT, Markdown, HTML, and EPUB, including the director correction pass below. No production rendering architecture was changed and no PDF, DOCX, browser, or Calibre scope was added.

The maintained matrix is [docs/qa/non-pdf-reader-parity.md](../../qa/non-pdf-reader-parity.md). It records source loading, canonical text, sentence/page accounting, anchors, search/navigation, text-only toggles, persistence, and TTS evidence separately for each supported non-PDF kind.

## Source / Session Contracts

`crates/lanternleaf-core/tests/non_pdf_parity.rs` loads representative sources through `ReaderSession::load_session_for_source`, rather than testing a mock parser. Hosted Windows runs execute the HTML and EPUB paths with Pandoc installed; the local machine lacks Pandoc, so those two paths are intentionally skipped locally. TXT and Markdown pass locally and in hosted validation.

The tests verify source kind, non-empty canonical sentences, sentence/page accounting, anchor cardinality, source-family-specific syntax-clean canonical text, and stable search content. They also verify persistence, reopen, and twice-invoked cache cleanup for temporary copies of the exercised sessions.

## Reader Interactions

The real-session tests cover search query, search next, search previous, selected-result identity, sentence click/highlight, play-from-highlight, and text-only toggling while preserving canonical sentences and the current audio cursor. Existing core session coverage supplies next/previous/repeat and page-navigation behavior. Interactive GUI execution remains in the manual Windows checklist.

## Pretty Projection / Anchor Mapping

The parity evidence uses the Rust-native pretty projection and anchor/session mapping already owned by the core reader. `crates/lanternleaf-egui/tests/non_pdf_pretty_parity.rs` inspects representative Markdown and HTML blocks plus deterministic EPUB chapter HTML for headings, paragraphs, emphasis, lists, links, images, and tables, with monotonic bounded block anchors. Existing mapping seams plus correction tests cover exact/nearest fallback identity and duplicate-jump suppression. No WebView or browser-owned production rendering was introduced.

## TTS Runtime Parity

`crates/lanternleaf-app/tests/non_pdf_tts_runtime.rs` runs all four real representative sessions through the backend-neutral simulated `TtsRuntime` when Pandoc is available. The common subset covers page start, highlight, seek next/previous, repeat, stop/cancellation, replacement after cancellation, progress cursor bounds, and backend-setting changes without reader-index forks. Local TXT/Markdown execution passes; hosted Windows executes HTML/EPUB as well.

## Persistence / Reopen

Representative sessions are persisted, reopened, checked for bookmark continuity, and cleaned from the cache. Cleanup is called twice per representative session with stable successful postconditions. The tests copy repository fixtures to temporary source paths so product cleanup cannot delete repository-owned fixtures. The broader existing persistence suite remains part of the hosted workspace test gate.
