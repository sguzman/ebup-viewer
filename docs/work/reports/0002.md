# Goal 0002 — Close Trustworthy Baseline

## Result

BLOCKED at the authorized PDF escalation boundary. The native startup error path, truthful launch-smoke gate, external prerequisite diagnostics, live abbreviation configuration, and PDF fixture harness repair are implemented. The remaining non-environment failures are seven PDF behavior/contract defects that belong to the explicitly deferred PDF Gate 3/4 work.

## Native Startup

- `eframe::run_native` errors are returned as `NativeRunError::Eframe` instead of being discarded.
- The root native entry point propagates startup errors and exits nonzero with an actionable message.
- The egui binary entry point reports startup errors to stderr and exits with code 1.
- Single-instance lock I/O failures and an already-running instance are distinct error cases.
- The Windows launch smoke no longer treats an early exit with code 0 as success. It requires the process to remain alive for the smoke interval; an early exit always fails the step.

## Changes

- Added typed native startup error propagation and preserved single-instance lock distinctions.
- Added `scripts/windows-dev-check.ps1`, which reports Rust, Cargo, CMake, Pandoc, MSVC, and MSBuild availability without attempting privileged installation.
- Updated Windows CI to initialize MSVC, install Pandoc when absent, run the prerequisite checker, and fail early native exits.
- Added the missing live `chap.`, `sect.`, and `Calif.` abbreviation entries.
- Repaired the PDF calibration fixture schema by supplying the required empty `sample.pages` arrays; the calibration and determinism harness tests now pass.
- Existing Rust source-ingestion smoke coverage exercises TXT, Markdown, and HTML routing. HTML coverage is now deterministic in CI through the Pandoc provisioning step.
