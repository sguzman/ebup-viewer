# Egui Testing Objectives

This document captures the core objectives for the egui testing and parity roadmap.

## Objectives
- Replace the legacy frontend-heavy test stack with a Rust-native testing and parity strategy suitable for an egui desktop app.
- Preserve explicit parity gating against current reader, PDF, TTS, starter, Calibre, and browser-tab behavior.
- Define a durable post-migration quality model for a native Rust desktop product.
