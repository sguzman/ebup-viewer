# Goal 0007 — Prebuilt Windows QA bundle for Gate 2 signoff

## Result

Implemented and published a self-contained Windows QA bundle from the accepted native `main` lineage. The bundle contains the real Windows executable, runtime configuration, the Pandoc executable required by the current HTML/EPUB ingestion path, the accepted representative corpus, a deterministic EPUB, and a bundle-relative launcher. No reader behavior, PDF subsystem, installer, signing, or release pipeline was added.

## Bundle Manifest

The documented manifest is [docs/qa/windows-qa-bundle-manifest.md](../../qa/windows-qa-bundle-manifest.md). The generated artifact also contains `BUNDLE-MANIFEST.txt`.

The staged paths are:

- `lanternleaf.exe`;
- `conf/*.toml` and `conf/pandoc/strip-nontext.lua`;
- `tools/pandoc/pandoc.exe`;
- `qa-sources/representative.txt`, `representative.md`, `representative.html`, and `representative.epub`;
- `run-lanternleaf-qa.ps1`.

Fonts remain system-resolved by egui and the application icon is compiled into the executable, so neither requires an additional bundle asset.

## Runtime Dependencies

The launcher runs with the extracted bundle as the working directory, sets process-local config/cache/log paths, and prepends the bundled Pandoc directory to `PATH`. The bundle therefore does not require Rust, MSVC, Pandoc, or a configured Piper model merely to launch and select Windows TTS. It creates only bundle-local `qa-logs/`, `qa-handoff/`, and `qa-cache/` directories.

## Representative QA Corpus

TXT, Markdown, and HTML reuse the accepted Goal 0006 project-owned fixtures. The build script creates a deterministic two-chapter EPUB with stable repeated search text and no copyrighted book content. The structural validator checks the EPUB container, package, and both chapters.

## QA Launcher

The launcher is [scripts/run-lanternleaf-qa.ps1](../../scripts/run-lanternleaf-qa.ps1) in source and is copied to the artifact root. From the extracted artifact directory, the exact human command is:

```powershell
.\run-lanternleaf-qa.ps1
```

It prints the fixture/log locations, waits for LanternLeaf to exit, preserves stdout/stderr and LanternLeaf rolling logs in a timestamped handoff directory, and returns the application exit code. `-ValidateOnly` performs deterministic prerequisite validation without launching the GUI.
